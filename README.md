# voca-lens

내 단어장 사진을 찍으면 영단어와 한글 뜻을 짝지어 플래시카드·객관식으로 외우는 안드로이드 앱. 개인용.

## 왜 만드나

기존 앱(단어장 사진 인식 앱 3종)을 써 보니:

- 100개 중 약 10개를 놓치고, 놓쳤다는 표시도 없음
- 인식 범위를 직접 골라도 오류가 많음
- 한 장씩만 올릴 수 있고, 대기 시간이 김
- 단어장 이름을 바꿀 수 없음
- 디자인이 오래됨

## 구성

| 항목 | 선택 |
|---|---|
| 짝짓기 | Gemini 3.8 Flash 무료 등급 (3.5 Flash-Lite와 비교 후 확정) |
| 누락·철자 대조 | Cloud Vision `DOCUMENT_TEXT_DETECTION` (월 1,000장 무료) |
| 앱 | Kotlin + Jetpack Compose, APK 직접 설치 |
| 서버 | Cloudflare Workers가 Gemini·Vision을 대신 호출 (무료 등급 하루 10만 요청) |
| API 키 | Workers 비밀 값으로만 보관. APK·저장소에는 넣지 않음, 해당 API만 쓰도록 키 제한 |
| 저장 | 폰 내부 저장 + 수동 파일 백업 |

## 인식 흐름

1. 갤러리에서 여러 장 선택 또는 촬영 (ML Kit 문서 스캐너로 페이지 펴기·자르기)
2. 긴 변 약 3000px로 줄여 전송 (12MP로 충분, 50MP는 느리고 노이즈가 많음)
3. Vision: 글자와 좌표를 그대로 읽음 → 철자의 기준
4. Gemini: 영단어–뜻 짝짓기만 담당, 스트리밍으로 받음. 지시문에 「고치지 말고 보이는 그대로」
5. 대조: Gemini 결과가 Vision 글자와 다르거나 Vision에만 있는 단어 → 노란색 표시, 기본값은 Vision 철자
6. 검수: 표시된 항목만 사진과 나란히 보여 주고 한 번 눌러 고름. 목표 1쪽 30초 이내

LLM은 희귀 단어를 흔한 단어로 「고칠」 수 있다(예: obsequious → obvious). 그래서 글자는 Vision, 짝은 Gemini를 믿는다.

## 촬영 안내 (앱 촬영 화면 문구)

- 페이지 네 모서리가 모두 보이게 찍어 주세요
- 밝은 곳에서, 그림자와 빛 반사 없이
- 페이지를 평평하게 펴 주세요
- 흔들리지 않게 잠시 멈춘 뒤 찍어 주세요

찍은 직후 흐림·모서리 잘림이 감지되면 「다시 찍기」를 권한다.

## 대기 화면

| 단계 | 화면 |
|---|---|
| 전송 직후 | 「단어 찾는 중…」, 사진 위 스캔 선 애니메이션 |
| Vision 결과 (1~2초, 추정) | 「단어 48개 발견」, 단어마다 상자 표시 |
| Gemini 스트리밍 | 「뜻 정리 중 12/48」, 카드가 한 장씩 추가 |
| 대조 완료 | 「확인 필요 3개」, 노란색 표시 |

여러 장은 동시에 처리하고 끝난 쪽부터 검수. 무료 등급 분당 한도에 걸리면 몇 장씩 순서대로 보냄.

## 학습

- 영→한 플래시카드, 객관식(오답 보기는 같은 단어장의 다른 뜻, 정답과 겹치는 뜻 제외)
- 다의어는 「,」「;」로 나눠 채점, 보기에는 원문
- 라이트너 상자 복습, 오답 모아 보기
- 단어장 이름 변경·삭제
- 카드 뒤집을 때만 Free Dictionary API로 영영 뜻 (캐시)

## 진행 순서

1. 실제 단어장 사진으로 정확도 시험: 누락 + 지어낸 뜻 합계 1% 이하, Flash vs Flash-Lite, 처리 시간
2. 촬영 → 대조 → 검수 → 저장
3. 플래시카드·객관식·오답 복습·디자인

## 나중에 다른 사용자가 생기면

- 스토어 등록 (Play 개인 계정은 테스터 12명 14일, 갤럭시 스토어 조건 미확인)
- 18세 이상 확인 체크, 성인 대상 안내 (Gemini API 약관: 18세 미만 대상 앱 금지)
- 개인정보처리방침에 「사진이 Google AI 개선에 쓰일 수 있음」 고지 (무료 등급)
- Workers 주소를 아무나 호출하지 못하게 앱 인증 추가
- 무료 한도는 프로젝트 단위라 사용자가 늘면 유료 전환 검토
- 광고는 스토어 등록 후 AdMob, 내 폰은 테스트 기기로 등록

가격·약관은 2026-11-19 기준 공식 문서로 확인. 시간·화질 수치 중 「추정」은 미검증.
